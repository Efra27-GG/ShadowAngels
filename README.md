# ShadowAngels

## Backend

Antes de ejecutar `backend/app.py`, instala las dependencias de Python.

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Si no usas entorno virtual, al menos ejecuta:

```powershell
cd backend
pip install -r requirements.txt
python app.py
```
